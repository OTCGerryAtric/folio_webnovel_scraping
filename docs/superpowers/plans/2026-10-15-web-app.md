# Folio Web App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local web app, Folio, that drives the existing book pipeline from any browser, with a bookshelf, live job progress, a watermark studio, a build panel, and a settings editor.

**Architecture:** A FastAPI package `scraper/web/` wraps the existing engine. Shared operations that `commands.py` currently keeps private (fetch new, clean and report, build files, add a book) become public functions there, so the CLI and the web call the same code. Long operations run as background jobs whose events stream to the browser over SSE. A Svelte 5 + Tailwind v4 single-page app in `web/` builds into `scraper/web/static/`, which is committed.

**Tech Stack:** Python 3.12, FastAPI, uvicorn, tomlkit, httpx (tests), pytest; Svelte 5, TypeScript, Vite, Tailwind CSS v4, Vitest, @fontsource (Fraunces, Inter), lucide-svelte.

**Spec:** `docs/superpowers/specs/2026-10-15-web-app-design.md`

## Global Constraints

- The engine is the only place scraping, cleaning and building happen. `scraper/web/` contains no such logic.
- The CLI behaves exactly as before. All existing tests keep passing, apart from the one deliberately moved in Task 3.
- No test touches the network. `get_page`, `get_bytes` and `fetcher_factory` are injected and stubbed.
- Every `{book}` in a URL resolves through `list_books(root)` by exact folder name. Every downloadable file name must be one of `book.outputs()`.
- API errors are JSON `{"error": "<message>"}`, using the same message text the CLI prints.
- The server binds `127.0.0.1` unless `--lan` is passed. With `--lan`, non-loopback `/api` requests need the access key cookie.
- `book.toml` is written through tomlkit, keeping comments. Nothing is written if validation through `build_settings` fails.
- The front end builds to `scraper/web/static/` (committed). Running Folio needs Python only.
- Run tests with `.venv/Scripts/python.exe -m pytest` (Git Bash) from the project root. Front-end tests use `npm test` in `web/`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Two jobs on one book at once** (double-clicking Update, or Update while a Clean is running): the second request returns 409 and the first is unaffected. Test in Task 7.
2. **A book folder with no `book.toml`** (made by hand in Explorer): the library still lists it, flagged as needing setup, rather than failing the whole list. Test in Task 6.
3. **Saving settings while the epub is open, or with an invalid regex**: an invalid value gives a 422 with the reason and `book.toml` is byte-for-byte unchanged. Test in Task 4.
4. **A book name or file name crafted to escape the folder** (`..%2F..`, `book.toml` as a "file"): 404, with nothing outside `03 Output` served or deleted. Test in Task 8.
5. **Cancelling a download, then pressing Update again**: the cancelled job keeps what it fetched, and the next run carries on from there with nothing re-fetched. Test in Task 7.

```python
def load_site_config(path: Path | str) -> dict:
    """Read a TOML site file, rejecting keys we would silently ignore."""
    path = Path(path)
    if not path.exists():
        raise ValueError(f"Site config not found: {path}")
    return parse_site_config(path.read_text(encoding="utf-8"), str(path))


def parse_site_config(text: str, source: str) -> dict:
    try:
        config = tomllib.loads(text)
    except tomllib.TOMLDecodeError as exc:
        raise ValueError(f"Could not parse {source}: {exc}") from exc
    unknown = sorted(set(config) - KNOWN_KEYS)
    if unknown:
        raise ValueError(
            f"Unknown setting(s) in {source}: {', '.join(unknown)}. "
            f"Valid keys: {', '.join(sorted(KNOWN_KEYS))}"
        )
    return config
```

```python
    if url_template:
        title = title or name
```

```python
"""Reading and writing a book's settings for the web app.

Writes go through tomlkit so the comments a person wrote in `book.toml`
survive, and every change is checked by `build_settings` first: an
invalid change leaves the file exactly as it was.
"""

from __future__ import annotations

import os
import tempfile

import tomlkit

from scraper.book import Book
from scraper.config import DEFAULTS, build_settings, parse_site_config

EDITABLE = (
    "title", "author", "source", "url_template", "start", "step",
    "content_selector", "title_selector", "remove_selectors",
    "dedupe", "dedupe_threshold", "strip_patterns", "trim_overlap", "overlap_window",
    "remove_phrases", "review_ignore", "build_every",
    "delay", "max_misses", "max_retries", "timeout",
)

_INTS = {k for k in EDITABLE if isinstance(DEFAULTS[k], int) and not isinstance(DEFAULTS[k], bool)}
_FLOATS = {k for k in EDITABLE if isinstance(DEFAULTS[k], float)}
_BOOLS = {k for k in EDITABLE if isinstance(DEFAULTS[k], bool)}
_LISTS = {k for k in EDITABLE if isinstance(DEFAULTS[k], list)}


def read_settings(book: Book) -> dict:
    text = book.config_path.read_text(encoding="utf-8")
    config = parse_site_config(text, str(book.config_path))
    return {
        "values": {k: config.get(k) for k in EDITABLE},
        "defaults": {k: DEFAULTS[k] for k in EDITABLE},
        "raw": text,
    }


def write_settings(book: Book, changes: dict) -> None:
    unknown = sorted(set(changes) - set(EDITABLE))
    if unknown:
        raise ValueError(f"These settings cannot be changed here: {', '.join(unknown)}")

    text = book.config_path.read_text(encoding="utf-8")
    config = parse_site_config(text, str(book.config_path))
    coerced = {k: _coerce(k, v) for k, v in changes.items()}
    for key, value in coerced.items():
        if value is None:
            config.pop(key, None)
        else:
            config[key] = value
    _check(book, config)

    doc = tomlkit.parse(text)
    for key, value in coerced.items():
        if value is None:
            if key in doc:
                del doc[key]
        elif key in _LISTS and isinstance(doc.get(key), list):
            _sync_array(doc[key], value)
        else:
            doc[key] = _item(value)
    _write(book, tomlkit.dumps(doc))


def write_raw(book: Book, text: str) -> None:
    _check(book, parse_site_config(text, str(book.config_path)))
    _write(book, text)


def _check(book: Book, config: dict) -> None:
    build_settings({"cache_dir": str(book.raw_dir)}, config, require_out=False)


def _coerce(key: str, value):
    if value is None or value == "":
        return None
    try:
        if key in _BOOLS:
            if not isinstance(value, bool):
                raise TypeError
            return value
        if key in _INTS:
            if isinstance(value, bool) or float(value) != int(float(value)):
                raise TypeError
            return int(float(value))
        if key in _FLOATS:
            if isinstance(value, bool):
                raise TypeError
            return float(value)
        if key in _LISTS:
            if not isinstance(value, list) or not all(isinstance(v, str) for v in value):
                raise TypeError
            return [v for v in value if v.strip()]
        if not isinstance(value, str):
            raise TypeError
        return value.strip()
    except (TypeError, ValueError):
        raise ValueError(f"{key} cannot be set to {value!r}") from None


def _string(value: str):
    if "'" in value or "\n" in value:
        return tomlkit.string(value)
    return tomlkit.string(value, literal=True)


def _item(value):
    if isinstance(value, str):
        return _string(value)
    if isinstance(value, list):
        array = tomlkit.array()
        for entry in value:
            array.append(_string(entry))
        if len(value) > 1:
            array.multiline(True)
        return array
    return value


def _sync_array(array, wanted: list[str]) -> None:
    """Change a list in place, so comments between its items stay put."""
    for index in reversed(range(len(array))):
        if str(array[index]) not in wanted:
            del array[index]
    have = [str(v) for v in array]
    for entry in wanted:
        if entry not in have:
            array.append(_string(entry))


def _write(book: Book, text: str) -> None:
    folder = book.config_path.parent
    handle, temp = tempfile.mkstemp(dir=folder, prefix=".book-", suffix=".toml")
    with os.fdopen(handle, "w", encoding="utf-8", newline="") as out:
        out.write(text)
    os.replace(temp, book.config_path)
```

```python
"""The watermark studio's working parts: repeated sentences with context,
trying a pattern against the whole book, and suggesting one.

Pure functions over cleaned pages. No network, no filesystem.
"""

from __future__ import annotations

import re

from scraper.review import normalise, repeated_sentences, split_sentences

MAX_SHARE = 0.02
_SNIPPET = 220


def review_rows(pages, min_chapters: int, ignore) -> list[dict]:
    repeats = repeated_sentences(pages, min_chapters=min_chapters, ignore=ignore)
    contexts: dict[str, list[dict]] = {r.key: [] for r in repeats}
    for page in pages:
        for block in page.body.split("\n\n"):
            for sentence in split_sentences(block):
                found = contexts.get(normalise(sentence))
                if found is not None and len(found) < 2 and all(c["chapter"] != page.number for c in found):
                    found.append({"chapter": page.number, "text": _snippet(block, sentence)})
    return [
        {"text": r.text, "key": r.key, "chapters": r.chapters, "first": r.first, "contexts": contexts[r.key]}
        for r in repeats
    ]


def test_pattern(pages, pattern: str, examples: int = 20) -> dict:
    if not pattern or not pattern.strip():
        raise ValueError("Enter a pattern to try.")
    try:
        compiled = re.compile(pattern, re.IGNORECASE)
    except re.error as exc:
        raise ValueError(f"That is not a valid pattern: {exc}") from None
    if compiled.search(""):
        raise ValueError("That pattern matches empty text, so it would remove every sentence.")

    total = matched = 0
    chapters, samples = set(), []
    for page in pages:
        for block in page.body.split("\n\n"):
            for sentence in split_sentences(block):
                sentence = sentence.strip()
                if not sentence:
                    continue
                total += 1
                match = compiled.search(sentence)
                if match:
                    matched += 1
                    chapters.add(page.number)
                    if len(samples) < examples:
                        samples.append({"chapter": page.number, "text": sentence,
                                        "start": match.start(), "end": match.end()})
    if total and matched / total > MAX_SHARE:
        raise ValueError(
            f"That pattern would remove {matched:,} of {total:,} sentences "
            f"({matched / total:.0%}). Make it more specific."
        )
    return {"sentences": matched, "chapters": len(chapters), "total": total, "examples": samples}


def suggest_pattern(sentence: str) -> str:
    """The sentence's words in order, with any punctuation or spacing between them."""
    words = re.findall(r"[^\W_]+", sentence)
    if not words:
        raise ValueError("That sentence has no words to match.")
    return r"[\W_]+".join(re.escape(word) for word in words)


def _snippet(block: str, sentence: str) -> str:
    block = " ".join(block.split())
    if len(block) <= _SNIPPET:
        return block
    at = max(block.find(sentence.strip()[:40]), 0)
    start = max(at - _SNIPPET // 3, 0)
    text = block[start:start + _SNIPPET]
    return ("…" if start else "") + text + ("…" if start + _SNIPPET < len(block) else "")
```

```python
"""What the library and book pages show: summaries, the chapter map,
built files, the site's latest chapter (cached), and covers."""

from __future__ import annotations

import re
import threading
import time
from datetime import datetime, timezone
from pathlib import Path

import requests

from scraper.book import Book, missing_numbers
from scraper.bookpage import parse_book_page
from scraper.fetch import DEFAULT_USER_AGENT
from scraper.stages import site_latest

_RANGE_RE = re.compile(r"(\d+)-(\d+)$")
_MAGIC = ((b"\xff\xd8", ".jpg"), (b"\x89PNG", ".png"), (b"GIF8", ".gif"))


def chapter_map(raw, cleaned, start: int, latest: int | None) -> list[list]:
    held, done = set(raw), set(cleaned)
    top = max([*held, latest or 0])
    newest = max(held, default=start - 1)
    runs: list[list] = []
    for number in range(start, top + 1):
        if number in held:
            state = "cleaned" if number in done else "raw"
        else:
            state = "new" if number > newest else "missing"
        if runs and runs[-1][0] == state and runs[-1][2] == number - 1:
            runs[-1][2] = number
        else:
            runs.append([state, number, number])
    return runs


def file_info(path: Path) -> dict:
    stat = path.stat()
    match = _RANGE_RE.search(path.stem)
    return {
        "name": path.name,
        "format": path.suffix.lower().lstrip("."),
        "size": stat.st_size,
        "modified": datetime.fromtimestamp(stat.st_mtime, timezone.utc).isoformat(),
        "first": int(match.group(1)) if match else None,
        "last": int(match.group(2)) if match else None,
    }


class SiteCache:
    """The site's latest chapter per book, asked for at most once per `ttl`."""

    def __init__(self, get_page, ttl: float = 900.0, clock=time.monotonic):
        self._get_page, self._ttl, self._clock = get_page, ttl, clock
        self._seen: dict[str, tuple[float, int | None]] = {}
        self._lock = threading.Lock()

    def peek(self, name: str) -> int | None:
        with self._lock:
            entry = self._seen.get(name)
        return entry[1] if entry else None

    def check(self, book: Book, settings, fresh: bool = False) -> int | None:
        with self._lock:
            entry = self._seen.get(book.name)
        if entry and not fresh and self._clock() - entry[0] < self._ttl:
            return entry[1]
        latest = site_latest(settings, self._get_page)
        with self._lock:
            self._seen[book.name] = (self._clock(), latest)
        return latest


def summary(book: Book, site: SiteCache) -> dict:
    raw, cleaned = book.raw_numbers(), book.cleaned_numbers()
    data = {
        "name": book.name, "title": book.name, "author": None, "source": None,
        "ready": True, "error": None,
        "downloaded": len(raw), "cleaned": len(cleaned),
        "first": min(raw, default=None), "last": max(raw, default=None),
        "missing": 0, "latest": site.peek(book.name), "new": 0, "build_every": 0,
        "outputs": [file_info(p) for p in book.outputs()],
        "has_cover": book.cover_path is not None,
    }
    try:
        settings = book.settings()
    except ValueError as exc:
        data.update(ready=False, error=str(exc))
        return data
    data.update(
        title=settings.title or book.name, author=settings.author, source=settings.source,
        build_every=settings.build_every,
        missing=len(missing_numbers(raw, settings.start, max(raw))) if raw else 0,
    )
    latest = data["latest"]
    if latest:
        data["new"] = max(latest - max(raw, default=settings.start - 1), 0)
    return data


def fetch_bytes(url: str) -> bytes | None:
    try:
        response = requests.get(url, timeout=20, headers={"User-Agent": DEFAULT_USER_AGENT})
    except requests.RequestException:
        return None
    return response.content if response.ok else None


def save_cover(book: Book, url: str, get_bytes) -> Path | None:
    data = get_bytes(url)
    suffix = _image_suffix(data or b"")
    if suffix is None:
        return None
    path = book.folder / f"cover{suffix}"
    path.write_bytes(data)
    return path


def ensure_cover(book: Book, get_page, get_bytes) -> None:
    """One attempt at a cover for a book that has a source page but no cover."""
    if book.cover_path is not None:
        return
    try:
        source = book.settings().source
        html = get_page(source) if source else None
        cover = parse_book_page(html, source).cover if html else None
    except ValueError:
        return
    if cover:
        save_cover(book, cover, get_bytes)


def _image_suffix(data: bytes) -> str | None:
    for magic, suffix in _MAGIC:
        if data.startswith(magic):
            return suffix
    if data[:4] == b"RIFF" and data[8:12] == b"WEBP":
        return ".webp"
    return None
```

```python
"""What each kind of job does: the same steps the CLI runs."""

from __future__ import annotations

from dataclasses import dataclass
from typing import Callable

from scraper.book import Book
from scraper.commands import build_files, clean_and_report, fetch_new
from scraper.stages import build


@dataclass
class Context:
    report: Callable[[str], None]
    progress: Callable[[int, int | None, str], None]
    should_stop: Callable[[], bool]
    get_page: Callable
    fetcher_factory: Callable


def _fetch(book: Book, settings, ctx: Context) -> list[int]:
    held = set() if settings.refresh else set(book.raw_numbers())
    count = [0]

    def on_chapter(number, end, outcome):
        count[0] += 1
        total = None
        if end is not None:
            total = len([n for n in range(settings.start, end + 1, settings.step) if n not in held])
        ctx.progress(count[0], total, f"Chapter {number}: {outcome}")

    return fetch_new(book, settings, ctx.fetcher_factory, ctx.get_page, ctx.report,
                     progress=on_chapter, should_stop=ctx.should_stop)


def _clean(book: Book, settings, ctx: Context):
    return clean_and_report(book, settings, ctx.report,
                            progress=lambda done, total: ctx.progress(done, total, "Cleaning"))


def run_download(book, params, ctx):
    settings = book.settings(start=params.get("start"), end=params.get("end"),
                             refresh=params.get("refresh") or None)
    return {"fetched": len(_fetch(book, settings, ctx))}


def run_clean(book, params, ctx):
    result = _clean(book, book.settings(), ctx)
    return {"cleaned": len(result.pages), "skipped": len(result.skipped)}


def run_build(book, params, ctx):
    settings = book.settings(build_every=params.get("every"))
    ctx.progress(0, None, "Building")
    paths = build_files(book, settings, fmt=params.get("format") or "epub",
                        start=params.get("start"), end=params.get("end"))
    for path in paths:
        ctx.report(f"Wrote {path.name}")
    return {"files": [p.name for p in paths]}


def run_update(book, params, ctx):
    settings = book.settings()
    fetched = _fetch(book, settings, ctx)
    if not fetched:
        ctx.report("Up to date: no new chapters.")
        return {"fetched": 0, "files": []}
    if ctx.should_stop():
        return {"fetched": len(fetched), "files": []}
    result = _clean(book, settings, ctx)
    path = build(book, settings, fmt=params.get("format") or "epub", start=min(fetched), end=max(fetched))
    ctx.report(f"Wrote {len(fetched)} new chapter(s) to {path.name}")
    return {"fetched": len(fetched), "cleaned": len(result.pages), "files": [path.name]}


RUNNERS = {"download": run_download, "clean": run_clean, "build": run_build, "update": run_update}
```

```python
"""Background jobs for the web app: one at a time per book, with every
line of output and every step of progress sent to whoever is listening."""

from __future__ import annotations

import json
import threading
import time
import traceback
import uuid
from collections import deque
from dataclasses import dataclass, field
from pathlib import Path

from scraper.book import Book, list_books
from scraper.web.tasks import RUNNERS, Context

_LOG_LINES = 500
_KEEP_ACTIVITY = 100
_KEEP_JOBS = 50
_PROGRESS_EVERY = 0.1  # seconds between progress events, except the last


class Busy(Exception):
    """The book already has a job running."""


@dataclass
class Job:
    book: str
    kind: str
    params: dict
    id: str = field(default_factory=lambda: uuid.uuid4().hex[:12])
    status: str = "queued"
    created: float = field(default_factory=time.time)
    started: float | None = None
    finished: float | None = None
    progress: dict | None = None
    summary: dict = field(default_factory=dict)
    error: str | None = None
    log: deque = field(default_factory=lambda: deque(maxlen=_LOG_LINES))
    stop: threading.Event = field(default_factory=threading.Event)
    done: threading.Event = field(default_factory=threading.Event)

    def to_dict(self, log: bool = True) -> dict:
        data = {k: getattr(self, k) for k in (
            "id", "book", "kind", "params", "status", "created", "started",
            "finished", "progress", "summary", "error")}
        if log:
            data["log"] = list(self.log)
        return data


class JobManager:
    def __init__(self, root, get_page, fetcher_factory):
        self.root = Path(root)
        self.get_page, self.fetcher_factory = get_page, fetcher_factory
        self._jobs: dict[str, Job] = {}
        self._listeners: list = []
        self._lock = threading.Lock()
        self._queue_lock = threading.Lock()  # update-all runs one book at a time

    # -- listeners ---------------------------------------------------------

    def add_listener(self, listener) -> None:
        with self._lock:
            self._listeners.append(listener)

    def remove_listener(self, listener) -> None:
        with self._lock:
            if listener in self._listeners:
                self._listeners.remove(listener)

    def _emit(self, event: dict) -> None:
        with self._lock:
            listeners = list(self._listeners)
        for listener in listeners:
            try:
                listener(event)
            except Exception:  # a broken listener must not break the job
                pass

    # -- starting and stopping ---------------------------------------------

    def start(self, book_name: str, kind: str, params: dict | None = None) -> Job:
        job = self._create(book_name, kind, params)
        threading.Thread(target=self._run, args=(job,), daemon=True).start()
        return job

    def start_update_all(self) -> list[Job]:
        jobs = []
        for book in list_books(self.root):
            try:
                if book.settings().source and self.running_for(book.name) is None:
                    jobs.append(self._create(book.name, "update", {}))
            except ValueError:
                continue

        def run_all():
            for job in jobs:
                if not job.stop.is_set():
                    with self._queue_lock:
                        self._run(job)
                else:
                    self._finish(job, "cancelled")
        threading.Thread(target=run_all, daemon=True).start()
        return jobs

    def cancel(self, job_id: str) -> Job:
        job = self.get(job_id)
        job.stop.set()
        return job

    def get(self, job_id: str) -> Job:
        with self._lock:
            job = self._jobs.get(job_id)
        if job is None:
            raise KeyError(job_id)
        return job

    def recent(self) -> list[Job]:
        with self._lock:
            return sorted(self._jobs.values(), key=lambda j: j.created, reverse=True)

    def running_for(self, book_name: str) -> Job | None:
        with self._lock:
            return next((j for j in self._jobs.values()
                         if j.book == book_name and j.status in ("queued", "running")), None)

    def wait(self, job_id: str, timeout: float = 10.0) -> Job:
        job = self.get(job_id)
        job.done.wait(timeout)
        return job

    # -- running -----------------------------------------------------------

    def _create(self, book_name: str, kind: str, params: dict | None) -> Job:
        if kind not in RUNNERS:
            raise ValueError(f"Unknown job {kind!r}. Use one of: {', '.join(RUNNERS)}")
        self._book(book_name)
        with self._lock:
            busy = next((j for j in self._jobs.values()
                         if j.book == book_name and j.status in ("queued", "running")), None)
            if busy is not None:
                raise Busy(f"{book_name} is already busy with {busy.kind}.")
            job = Job(book=book_name, kind=kind, params=dict(params or {}))
            self._jobs[job.id] = job
            for old in sorted(self._jobs.values(), key=lambda j: j.created)[:-_KEEP_JOBS]:
                if old.done.is_set():
                    del self._jobs[old.id]
        self._emit({"type": "job", "job": job.to_dict(log=False)})
        return job

    def _book(self, name: str) -> Book:
        for book in list_books(self.root):
            if book.name == name:
                return book
        raise ValueError(f"No book called {name!r}")

    def _run(self, job: Job) -> None:
        job.status, job.started = "running", time.time()
        self._emit({"type": "job", "job": job.to_dict(log=False)})
        last = [0.0]

        def report(line: str) -> None:
            job.log.append(line)
            self._emit({"type": "log", "job": job.id, "book": job.book, "line": line})

        def progress(done: int, total: int | None, label: str) -> None:
            job.progress = {"done": done, "total": total, "label": label}
            now = time.monotonic()
            if now - last[0] >= _PROGRESS_EVERY or (total is not None and done >= total):
                last[0] = now
                self._emit({"type": "progress", "job": job.id, "book": job.book, "progress": job.progress})

        ctx = Context(report=report, progress=progress, should_stop=job.stop.is_set,
                      get_page=self.get_page, fetcher_factory=self.fetcher_factory)
        try:
            job.summary = RUNNERS[job.kind](self._book(job.book), job.params, ctx) or {}
            self._finish(job, "cancelled" if job.stop.is_set() else "done")
        except (ValueError, OSError) as exc:
            job.error = str(exc)
            report(f"error: {exc}")
            self._finish(job, "error")
        except Exception as exc:  # report the unexpected rather than lose it in a thread
            job.error = f"Unexpected error: {exc}"
            for line in traceback.format_exc().splitlines():
                job.log.append(line)
            self._finish(job, "error")

    def _finish(self, job: Job, status: str) -> None:
        job.status, job.finished = status, time.time()
        try:
            _append_activity(self._book(job.book), job)
        except (ValueError, OSError):
            pass
        job.done.set()
        self._emit({"type": "job", "job": job.to_dict(log=False)})


def read_activity(book: Book, limit: int = 20) -> list[dict]:
    path = book.activity_path
    if not path.exists():
        return []
    records = []
    for line in path.read_text(encoding="utf-8").splitlines():
        try:
            records.append(json.loads(line))
        except json.JSONDecodeError:
            continue
    return list(reversed(records))[:limit]


def _append_activity(book: Book, job: Job) -> None:
    record = {k: v for k, v in job.to_dict(log=False).items() if k not in ("progress",)}
    path = book.activity_path
    lines = path.read_text(encoding="utf-8").splitlines() if path.exists() else []
    lines = [*lines, json.dumps(record)][-_KEEP_ACTIVITY:]
    path.write_text("\n".join(lines) + "\n", encoding="utf-8")
```

```python
"""Start Folio: pick a port, open the browser, and on --lan print a link
(with its access key) for other devices on the network."""

from __future__ import annotations

import secrets
import socket
import sys
import threading
import webbrowser

import uvicorn

from scraper.web.app import create_app


def free_port(host: str, start: int = 8765) -> int:
    for port in range(start, start + 50):
        with socket.socket() as probe:
            try:
                probe.bind((host, port))
            except OSError:
                continue
            return port
    raise OSError(f"No free port between {start} and {start + 49}")


def lan_address() -> str:
    with socket.socket(socket.AF_INET, socket.SOCK_DGRAM) as probe:
        try:
            probe.connect(("10.255.255.255", 1))  # no packet is sent
            return probe.getsockname()[0]
        except OSError:
            return "127.0.0.1"


def serve(root, lan: bool = False, port: int | None = None, open_browser: bool = True,
          run=uvicorn.run, report=None) -> int:
    report = report or (lambda message: print(message, file=sys.stderr))
    host = "0.0.0.0" if lan else "127.0.0.1"
    port = port or free_port(host)
    key = secrets.token_urlsafe(12) if lan else None
    app = create_app(root=root, lan_key=key)

    local = f"http://127.0.0.1:{port}/"
    report(f"Folio is running at {local}")
    if lan:
        remote = f"http://{lan_address()}:{port}/?key={key}"
        report(f"On your phone or tablet (same Wi-Fi): {remote}")
        _print_qr(remote, report)
    report("Press Ctrl-C to stop.")

    if open_browser:
        threading.Timer(1.0, webbrowser.open, args=(local,)).start()
    run(app, host=host, port=port, log_level="warning")
    return 0


def _print_qr(text: str, report) -> None:
    try:
        import qrcode
    except ImportError:
        return
    qr = qrcode.QRCode(border=1)
    qr.add_data(text)
    qr.make()
    rows = qr.get_matrix()
    for top, bottom in zip(rows[::2], rows[1::2] + [[False] * len(rows[0])]):
        report("".join("█" if a and b else "▀" if a else "▄" if b else " " for a, b in zip(top, bottom)))
```

`blocks.ts`. The algorithm mirrors `build_blocks`: when every > 0, each block index is `floor((n-1)/every)`, and block bounds `[i*every+1, (i+1)*every]` are clamped to start/end. The name comes from the first and last cleaned numbers actually inside the block (as `build` names its files).

```ts
export interface PlannedFile { first: number; last: number; name: string }
export function planBuild(cleaned: number[], o: { every: number; start?: number; end?: number; bookName: string; format: string }): PlannedFile[] {
  const nums = cleaned.filter(n => (o.start == null || n >= o.start) && (o.end == null || n <= o.end)).sort((a, b) => a - b)
  if (!nums.length) return []
  const file = (inBlock: number[]) => {
    const first = inBlock[0], last = inBlock[inBlock.length - 1]
    return { first, last, name: `${o.bookName} ${first}-${last}.${o.format.toLowerCase()}` }
  }
  if (!o.every) return [file(nums)]
  const blocks = new Map<number, number[]>()
  for (const n of nums) {
    const i = Math.floor((n - 1) / o.every)
    blocks.set(i, [...(blocks.get(i) ?? []), n])
  }
  return [...blocks.keys()].sort((a, b) => a - b).map(i => file(blocks.get(i)!))
}
```

```ts
export function describeRanges(nums: number[]): string {
  const s = [...nums].sort((a, b) => a - b)
  if (!s.length) return 'none'
  const out: string[] = []
  let first = s[0], last = s[0]
  for (const n of s.slice(1)) {
    if (n === last + 1) { last = n; continue }
    out.push(first === last ? `${first}` : `${first}-${last}`); first = last = n
  }
  out.push(first === last ? `${first}` : `${first}-${last}`)
  return out.join(', ')
}
export function formatBytes(n: number): string {
  if (n < 1024) return `${n} B`
  const units = ['KB', 'MB', 'GB']; let v = n / 1024; let u = 0
  while (v >= 1024 && u < units.length - 1) { v /= 1024; u++ }
  return `${v.toFixed(1)} ${units[u]}`
}
export function eta(done: number, total: number | null, perSecond: number): string {
  if (!total || !perSecond || done >= total) return ''
  const s = Math.round((total - done) / perSecond)
  return s < 60 ? `about ${s}s left` : `about ${Math.round(s / 60)} min left`
}
export function timeAgo(when: string | number): string {
  const t = typeof when === 'number' ? when * 1000 : Date.parse(when)
  const s = Math.max(0, (Date.now() - t) / 1000)
  if (s < 60) return 'just now'
  if (s < 3600) return `${Math.floor(s / 60)} min ago`
  if (s < 86400) return `${Math.floor(s / 3600)} h ago`
  return `${Math.floor(s / 86400)} d ago`
}
```
